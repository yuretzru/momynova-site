# Сайт центра Тажигуль Момыновой

Статический лендинг «Центр психоэнергетической трансформации личности Тажигуль Момыновой». Публикуется через GitHub Pages из ветки `main`.

## Что менять

- **WhatsApp и соцсети** — объект `CONFIG` в начале `script.js`. Соцсети без ссылки на сайте не показываются.
- **Видеоотзывы** — атрибут `data-video` у карточек `.story` в `index.html` (ссылка YouTube embed вида `https://www.youtube.com/embed/ID` или путь к `.mp4`).
- **Тексты** — прямо в `index.html`.

## Локальный просмотр

```bash
python3 -m http.server 8000
```
